# A collection of popular and classic machine learning algorithms implemented at home

Models are organized by folders in `models/`, each model has a corresponding Jupyter Notebook in `notebooks/` titled `run_{model_name}.ipynb` which demonstrate how to run the full training and inference pipeline.

Example structure:

```
models/
    multilayer_perceptron/
        __init__.py
        multilayer_perceptron.py

...

notebooks/
    run_mlp.ipynb   # corresponding tutorial notebook

```
